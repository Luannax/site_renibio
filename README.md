## 📸 Adicionando Imagens dos Produtos

<details>
<summary><b>Ver instruções de imagens</b></summary>

### Estrutura de Pastas

```text
images/
├── kombucha/
│   ├── 1.jpeg
│   ├── 2.jpeg
│   └── 3.jpeg
├── kefir/
│   ├── 1.jpeg
│   └── 2.jpeg
├── pao/
│   ├── 1.jpeg
│   ├── 2.jpeg
│   └── 3.jpeg
```

### Como nomear as fotos

- Para UMA foto: `1.jpeg`
- Para várias fotos: `1.jpeg`, `2.jpeg`, `3.jpeg`...

### 💡 Dicas de fotos

| Produto   | Sugestão de Fotos                |
|-----------|----------------------------------|
| Kombucha  | Garrafa, detalhe, em uso         |
| Kefir     | Pote fechado, textura            |
| Pão       | Pão inteiro, fatia, ingredientes |

### 🎨 Recomendações

- Formato: JPG ou PNG
- Tamanho: 400x400px
- Peso: até 500KB
- Boa iluminação

### ⚡ Galeria Inteligente

- 1 foto: sem navegação
- 2+ fotos: carrossel automático/manual
- Fallback: mostra ícone se não houver foto

</details>

## ⚙️ Configuração Rápida

1. Faça upload dos arquivos para seu servidor web
2. Adicione as fotos dos produtos em `images/`
3. Personalize contatos em `index.html`
4. Altere o número do WhatsApp em `script.js`
5. Teste tudo no navegador
